# Persian RAG GUI

> پرسش و پاسخ هوشمند از کتاب‌های فارسی، با رابط کاربری گرافیکی

یک برنامه‌ی دسکتاپ برای پرسش و پاسخ از کتاب‌هایی که با [Persian PDF Extractor](https://github.com/) به JSONL تبدیل شده‌اند. برنامه از **RAG** (Retrieval-Augmented Generation) استفاده می‌کند و کاملاً به‌صورت **آفلاین** روی کامپیوتر شما اجرا می‌شود.

## ویژگی‌ها

- 🎨 **رابط کاربری فارسی** با چیدمان RTL
- 💾 **ذخیره‌سازی خودکار جلسه** — دفعه‌ی بعد بلافاصله آماده است
- 🔍 **افزودن یا بازسازی ایندکس** — کتاب جدید بدون از دست دادن قبلی‌ها
- 📚 **نمایش همیشگی متن‌های بازیابی‌شده** قبل از پاسخ مدل
- 🤖 **کلید روشن/خاموش LLM** — می‌توانید فقط متن‌ها را ببینید
- ⚡ **پردازش در Thread جداگانه** — رابط کاربری فریز نمی‌شود
- 🌐 **پشتیبانی از هر مدلی در Ollama** — qwen2.5، deepseek-r1، llama3.1 و ...
- 🖥 **کاملاً آفلاین** — نیازی به API خارجی یا اینترنت نیست
- 🆓 **رایگان و متن‌باز**

## پیش‌نیازها

### ۱. Python 3.10 یا بالاتر

از [python.org](https://www.python.org/downloads/) دانلود کنید.

### ۲. Ollama

از [ollama.com](https://ollama.com/download) دانلود و نصب کنید.

سپس مدل‌های لازم را دانلود کنید:

```bash
# مدل Embedding (برای تبدیل متن به بردار)
ollama pull nomic-embed-text
# یا (توصیه‌شده برای فارسی)
ollama pull bge-m3

# مدل زبانی (برای تولید پاسخ)
ollama pull qwen2.5:7b
# یا
ollama pull deepseek-r1:7b
# یا
ollama pull llama3.1
```

### ۳. فایل‌های JSONL

این برنامه روی فایل‌هایی کار می‌کند که با **Persian PDF Extractor** تولید شده‌اند. اگر ندارید، از آن پروژه استفاده کنید تا کتاب‌های PDF خود را به JSONL تبدیل کنید.

## استفاده

### اجرای اول

1. روی **«📂 انتخاب پوشه»** بزنید و پوشه‌ای که فایل‌های `.jsonl` در آن است را انتخاب کنید
2. لیست کتاب‌ها در سایدبار سمت راست ظاهر می‌شود
3. روی **«🔍 افزودن به ایندکس»** بزنید و صبر کنید تا نوار پیشرفت کامل شود
4. حالا آماده‌ی پرسش هستید!

### اجرای بعدی

برنامه **خودکار جلسه‌ی قبلی را بازیابی می‌کند**. نیازی به انتخاب دوباره‌ی پوشه یا ایندکس نیست.

### پرسیدن سؤال

سؤالتان را در کادر پایین بنویسید و **Enter** بزنید.

```
👤  شما
تفسیر آیه‌ی اول سوره‌ی یونس چیست؟

📚  متن‌های بازیابی‌شده (5 مورد)
━━━ [1] al_mizan_j10 — ص 22 ━━━
[متن تکه]

━━━ [2] al_mizan_j10 — ص 23 ━━━
[متن تکه]

🤖  پاسخ مدل
آیه‌ی اول سوره‌ی یونس با حروف مقطعه‌ی «الر» آغاز می‌شود...
```

### حالت‌های پرسش

| چک‌باکس LLM | چه اتفاقی می‌افتد |
|---|---|
| ✅ **روشن** | متن‌ها + پاسخ مدل نمایش داده می‌شود |
| ⬜ **خاموش** | فقط متن‌های بازیابی‌شده، بدون فراخوانی LLM (سریع‌تر) |

### افزودن کتاب جدید

1. **«📂 انتخاب پوشه»** → پوشه‌ی جدید
2. **«🔍 افزودن به ایندکس»** → فقط کتاب‌های جدید اضافه می‌شوند

### بازسازی کامل

اگر مدل Embedding را عوض کردید یا می‌خواهید از صفر شروع کنید:

1. **«♻ بازسازی کامل»** → تأیید

## تنظیمات

با کلیک روی **«⚙ تنظیمات»** در سایدبار:

| فیلد | پیش‌فرض | توضیح |
|---|---|---|
| آدرس Ollama | `http://localhost:11434` | معمولاً همین کافی است |
| مدل Embedding | `nomic-embed-text` | برای فارسی `bge-m3` بهتر است |
| مدل پاسخ‌گو | `qwen2.5:7b` | `deepseek-r1` برای استدلال، `llama3.1` عمومی |
| اندازه‌ی تکه | `400` | کاراکترهای هر chunk (پیشنهاد: 300–500) |
| همپوشانی | `60` | کاراکترهای مشترک بین chunkهای متوالی |
| تعداد نتایج | `5` | تعداد chunkهای بازیابی‌شده (3 تا 10) |
| دمای مدل | `0.1` | خلاقیت مدل (0=دقیق، 1=خلاق) |
| اسکن بازگشتی | خاموش | جستجو در زیرپوشه‌ها |

### تنظیمات پیشنهادی برای فارسی

```
مدل Embedding : bge-m3
مدل پاسخ‌گو   : qwen2.5:7b
اندازه‌ی تکه  : 400
همپوشانی      : 60
تعداد نتایج    : 5
دمای مدل       : 0.1
```

### فایل‌های ذخیره‌سازی

```
~/.persian_rag/
├── config.json       ← تنظیمات مدل، chunk، top_k
├── session.json      ← جلسه‌ی ذخیره‌شده
└── chroma/           ← پایگاه داده‌ی برداری
```

## نکات عملکردی

### انتخاب مدل مناسب

| کاربرد | مدل پیشنهادی |
|---|---|
| پرسش و پاسخ سریع | `qwen2.5:7b` |
| استدلال پیچیده | `deepseek-r1:14b` |
| عمومی و متعادل | `llama3.1:8b` |
| سیستم ضعیف | `qwen2.5:3b` |

### زمان تقریبی ایندکس

برای ۱۰٬۰۰۰ تکه:

| مدل Embedding | زمان (CPU) | زمان (GPU) |
|---|---|---|
| `nomic-embed-text` | ۲۰–۴۰ دقیقه | ۳–۵ دقیقه |
| `bge-m3` | ۴۰–۶۰ دقیقه | ۵–۸ دقیقه |

### مصرف منابع

- **RAM**: ~۱–۲ GB برای ایندکس + ~۵۰۰ MB برای هر مدل بارگذاری‌شده
- **دیسک**: ~۵۰ MB برای ChromaDB (۱۰٬۰۰۰ تکه)
- **GPU**: اختیاری ولی سرعت را ۵–۱۰ برابر می‌کند

## عیب‌یابی

### `ImportError: langchain_text_splitters`

```bash
pip install langchain-text-splitters
```

### `Ollama: قطع ❌`

مطمئن شوید Ollama اجراست:

```bash
ollama serve
```

### `model not found`

مدل را دانلود کنید:

```bash
ollama pull qwen2.5:7b
```

### پاسخ‌ها بی‌ربط هستند

۱. مدل Embedding را به `bge-m3` عوض کنید
۲. **بازسازی کامل** بزنید
۳. `top_k` را کم کنید (مثلاً ۳)

### کندی پاسخ

۱. چک‌باکس LLM را بردارید — فقط متن‌ها (سریع)
۲. مدل سبک‌تر استفاده کنید (`qwen2.5:3b`)
۳. `top_k` را کم کنید

### خطای حافظه

- تعداد نتایج (`top_k`) را کم کنید
- مدل سبک‌تر استفاده کنید
